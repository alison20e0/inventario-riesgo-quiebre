# ADR-002: RabbitMQ para integrar con el sistema de compras

- **Tipo:** Tecnológica
- **Estatus:** Aceptado

## Contexto
El sistema de compras es externo y puede estar caído cuando se aprueba una recomendación.

## Decisión
Publicar el evento RecomendacionAprobada en RabbitMQ con reintentos y DLQ, en lugar de una llamada REST síncrona.

## Justificación
La aprobación no depende de la disponibilidad de compras y no se pierden órdenes.

## Consecuencias
Hay que operar un broker y diseñar consumidores idempotentes.
